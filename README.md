# Let's Digital — Shah Faisal Portfolio

A lightweight, responsive portfolio website for Shah Faisal / Let's Digital.

## Run locally

Serve this directory with any static file server, for example:

```sh
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Publish

This is a static website. Publish the repository root with GitHub Pages (or any static hosting provider); no build step, framework runtime, or package installation is required.

## Included

- Shopify, WordPress/WooCommerce, business website, digital marketing, AI UGC creative, mobile app, performance and AI workflow services.
- Responsive navigation, theme toggle, scroll progress, native scroll-reveal motion, and reduced-motion support.
- Optimized local WebP photos and project screenshots, including the live Sulal Entrepreneur UK site preview linked to its website.
- Project enquiry form that opens a prefilled WhatsApp draft for the visitor to review and send.

The portrait remains the supplied photo; it is cropped and lightly optimized for the page, with no face-changing edits. Work screenshots are portfolio previews; external brands and websites remain their owners' property.
